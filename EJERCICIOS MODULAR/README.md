# Módulo de Aprendizaje: Programación Modular en C

En esta sección del curso **Fundamentos de Programación**, empecé a aplicar el paradigma modular. El objetivo es dejar de escribir todo el código en el `main` y empezar a crear funciones independientes, reutilizables y fáciles de testear.

###  Lo que estoy aprendiendo aquí:
* **Abstracción:** Dividir un problema matemático complejo en submódulos lógicos.
* **Pasaje por Referencia:** Uso de punteros para modificar variables desde fuera de la función principal (muy usado en mis funciones de `leer`).
* **Mantenibilidad:** Escribir código que sea fácil de corregir sin romper todo el programa.
